# Communication preferences

- In user-facing fantasy basketball discussion, use players' surnames by default. Do not alternate between first names and surnames for the same player.
- Use a first name, initial, or full name only when needed to distinguish players with the same surname or otherwise avoid ambiguity (for example, Amen Thompson versus Ausar Thompson, or Derrick Jones Jr. versus other players named Jones).
- Refer to Reed Sheppard as **Sheppard**, not **Reed**; Reed can be mistaken for Paul Reed. Preserve the correct surname spelling.
- Use full verified names and ESPN player IDs in transaction payloads and audit records when needed for unambiguous identification.
- In streaming recommendations, put the primary and each backup in the same compact comparison table in the reply. Name each player's NBA team, position or rotation role, and the opponent, venue and tip time (Pacific). Show the remaining play dates.
- Use the last five completed team games for player minutes and league fantasy points, team fantasy points per game, and opponent fantasy points allowed and defensive rating with ranks. Label estimates. Name the teammates who share minutes or create the opportunity, their minutes and fantasy points per appearance, and what changes if an absent teammate returns. Include sample sizes for plays/sits splits. Use a second table if putting everything in one would make it hard to read.
